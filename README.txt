공익법인 인증마크 제도 — 실행 및 구현 안내

1. 실행
   index.html을 웹 브라우저에서 열면 됩니다. 별도 설치는 필요하지 않습니다.

2. 구현 환경
   HTML, CSS, JavaScript만 사용했습니다. 서버와 데이터베이스는 사용하지 않았습니다.
   최신 Chrome, Edge, Safari 등에서 이용할 수 있습니다.

3. 메뉴 구조
   홈 → 공익법인 검색 → 법인 상세(기본정보 / 운영·재정정보 / 주요 활동 / 자료실)
   홈 → 운영 정보 / 인증 안내 / 통계·보고서 → 상세 보고서 / 공지사항 / 관심 법인 / 내 정보(로그인·회원가입)

4. 시스템 구조
   HTML 화면 → JavaScript 화면 전환·검색·필터·정렬 → JavaScript 예시 데이터
   관심 법인 ↔ 브라우저 localStorage
   시연용 로그인 상태 ↔ 현재 탭의 sessionStorage
   CSS는 PC와 모바일 화면의 스타일을 담당합니다.

5. 데이터 및 제한 사항
   모든 법인 정보, 인증 상태, 수치와 공지는 시연용 예시입니다.
   로그인과 회원가입은 실제 계정 없이 아무 아이디와 비밀번호로 체험할 수 있습니다.
   비밀번호는 저장되지 않으며, 로그인 상태는 현재 브라우저 탭에서만 유지됩니다.
   실제 인증 심사 및 데이터 연동은 제공되지 않습니다.
   관심 목록은 현재 브라우저에 저장되며 브라우저 데이터를 삭제하면 사라질 수 있습니다.

6. 화면 이미지
   첫 화면의 나무와 방패 일러스트는 ImageGen으로 제작한 hero-illustration.png입니다.
   HTML, CSS, JavaScript와 같은 폴더에 있어야 배경이 표시됩니다.
